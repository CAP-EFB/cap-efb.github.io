# cap-efb.github.io

Landing page for [Mission Log](https://github.com/CAP-EFB/cap-mission-log), served at
https://cap-efb.github.io/. It links to the app and explains how to install it on an iPad.

A single static `index.html` with its icons; there is no build step. Pushing to `main` publishes it.

Mission Log is a personal tool made by a CAP member. It is not an official Civil Air Patrol product.
